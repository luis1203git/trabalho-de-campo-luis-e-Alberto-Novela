# Sistema de Gestão de Expedientes (SGE)

Sistema académico de Gestão de Expedientes com Controlo de Acesso Baseado em Papéis (RBAC).

## Estrutura
- `src/` — código-fonte organizado por módulos
- `database/` — modelo e scripts da base de dados
- `tests/` — testes por módulo
- `docs/` — requisitos, UML, arquitetura e testes
- `config/` — configurações do projeto
- `scripts/` — scripts auxiliares

> Esta estrutura organiza o trabalho real do projeto. Os ficheiros de implementação devem ser preenchidos com o código e artefactos efetivamente desenvolvidos pela equipa.
